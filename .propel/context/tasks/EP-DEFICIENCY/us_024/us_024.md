## Description
As compliance staff, I want records without confirmed deficiencies blocked so that no unsupported POC is created.
## Acceptance Criteria
### AC-001: Enforce deficiency prerequisite
- **Given**: A record with no confirmed deficiency
- **When**: POC generation is requested
- **Then**: the record remains incomplete and no POC job is published
## Edge Cases
- A previously confirmed deficiency removed by correction invalidates pending POC work.
