# User Story - US_002

## Story ID
US_002

## Story Title
Provision Azure Runtime Services

## Status
- **State**: Draft
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
As a platform engineer, I want isolated Azure runtime resources so that the compliance application can operate with controlled network and data boundaries.

## Acceptance Criteria

### AC-001: Deploy runtime resources
- **Given**: An approved Azure subscription and deployment configuration
- **When**: The infrastructure deployment runs
- **Then**: It provisions a Container Apps environment, PostgreSQL Flexible Server, Blob Storage, and Service Bus resources
- **And**: Public access to PostgreSQL is disabled or restricted by the approved network policy

### AC-002: Enforce storage lifecycle
- **Given**: A source-document storage container exists
- **When**: Its lifecycle policy is applied
- **Then**: The policy is versioned with the deployment configuration and can be evaluated before promotion

## Edge Cases
- A partial deployment fails without reporting the environment ready; the deployment output identifies the failed resource for an operator retry.
