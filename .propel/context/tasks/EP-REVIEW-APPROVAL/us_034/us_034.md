## Story Title
Enforce POC Approval Gate
## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
As compliance staff, I want approval enforced before POC use so that no unreviewed POC is available for submission.
## Acceptance Criteria
### AC-001: Approve eligible POC
- **Given**: A reviewed POC with all required elements and CMS support
- **When**: authorized staff approves it
- **Then**: the system transactionally records approval and makes it available for authorized use
## Edge Cases
- A rejected or incomplete POC remains unavailable for use or submission.
