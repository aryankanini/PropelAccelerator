# User Story - US_027
## Story ID
US_027
## Story Title
Generate One POC Per Deficiency
## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
As compliance staff, I want a separate POC draft for each deficiency so that corrective actions remain specific.
## Acceptance Criteria
### AC-001: Save deficiency-specific drafts
- **Given**: Confirmed deficiencies with approved source context
- **When**: the POC job completes
- **Then**: it persists exactly one draft linked to each deficiency and its source-set version
## Edge Cases
- A generation failure records the deficiency-specific error and leaves the deficiency available for manual drafting.
