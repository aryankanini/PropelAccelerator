## Description
As a release manager, I want versioned AI evaluation results so that prompt or model changes do not regress compliance quality.
## Acceptance Criteria
### AC-001: Gate AI changes
- **Given**: A proposed model or prompt version
- **When**: release evaluation runs
- **Then**: extraction, SOD recall, citation support, POC quality, refusal, and conditional-field results are recorded against a versioned test set
## Edge Cases
- A missing evaluation category blocks release promotion.
