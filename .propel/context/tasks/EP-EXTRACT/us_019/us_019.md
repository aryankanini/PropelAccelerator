## Story Title
Flag Uncertain Extraction Results
## Status
- **State**: Draft
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
As compliance staff, I want uncertain extraction results flagged so that I can correct them before approval.
## Acceptance Criteria
### AC-001: Record review flags
- **Given**: Missing, ambiguous, or below-threshold extraction evidence
- **When**: schema validation evaluates the result
- **Then**: the field status is incomplete or low-confidence and it is not represented as complete
## Edge Cases
- A malformed AI response is rejected and recorded as a failure state without partial unvalidated fields.
