## Description
As an application developer, I want typed repositories and transactions so that workflow state changes remain consistent.

## Acceptance Criteria

### AC-001: Commit related review changes
- **Given**: A valid review decision and revision update
- **When**: The review service persists the decision
- **Then**: The approval state and audit revision commit in one transaction or neither change is stored

## Edge Cases
- A database connection failure returns a recoverable error without reporting the decision as approved.
