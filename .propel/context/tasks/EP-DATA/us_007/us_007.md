# User Story - US_007

## Story ID
US_007

## Story Title
Store Immutable Document Evidence

## Status
- **State**: Draft
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
As compliance staff, I want uploaded forms and evidence snapshots stored with provenance so that reviewers can locate the original content.

## Acceptance Criteria

### AC-001: Record document provenance
- **Given**: An accepted document upload
- **When**: The source bytes are stored in object storage
- **Then**: The database records object identity, media type, and a computed content hash

## Edge Cases
- A computed hash mismatch marks the upload failed and prevents downstream processing.
