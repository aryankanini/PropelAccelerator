## Story Title
Persist Idempotent Job Attempts

## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
As an operator, I want durable job-attempt state so that retries do not duplicate workflow results.

## Acceptance Criteria

### AC-001: Detect duplicate attempt
- **Given**: A job with a stable processing-record and attempt identity
- **When**: The same job command is persisted twice
- **Then**: The second write returns the existing job outcome without creating a duplicate command record

## Edge Cases
- Concurrent inserts for one job identity result in one persisted job and one recoverable duplicate response.
