## Story Title
Persist Compliance Workflow Records

## Status
- **State**: Draft
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
As compliance staff, I want durable processing, field, deficiency, POC, and revision records so that each survey workflow is traceable.

## Acceptance Criteria

### AC-001: Store workflow relationships
- **Given**: A valid processing workflow
- **When**: Fields, deficiencies, POCs, and revisions are saved
- **Then**: Each record has the required parent identifier and referential integrity prevents an orphaned record

## Edge Cases
- Deleting a processing record with retained audit data is rejected by the persistence boundary.
