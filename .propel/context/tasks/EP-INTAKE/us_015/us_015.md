# User Story - US_015

## Story ID
US_015

## Story Title
Correlate Intake Processing Work

## Status
 **State**: WIP

## Description
As an operator, I want intake events correlated with queued work so that a submitted document can be investigated end to end.

## Acceptance Criteria

### AC-001: Queue identifiable extraction work
- **Given**: A successfully classified processing record
- **When**: Intake schedules extraction
- **Then**: The queued command contains its processing-record identifier and correlation identifier and is persisted before publication

## Edge Cases
- A queue publication failure leaves the record in a retryable state rather than indicating extraction has started.
