# User Story - US_013

## Story ID
US_013

## Story Title
Reject Unsafe Document Intake

## Status
- **State**: Draft
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
As compliance staff, I want unsafe or unreadable uploads routed to a clear error state so that unreliable content cannot enter approval.

## Acceptance Criteria

### AC-001: Block invalid intake
- **Given**: An unreadable, unsupported, or unauthorized upload request
- **When**: Intake validates it
- **Then**: It returns a sanitized error outcome, records the access attempt when unauthorized, and creates no approved processing record

## Edge Cases
- A file type spoofed by its extension is rejected after content inspection without executing embedded content.
