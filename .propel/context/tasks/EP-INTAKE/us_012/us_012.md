# User Story - US_012

## Story ID
US_012

## Story Title
Classify Survey Form Format

## Status
 **State**: WIP

## Description
As compliance staff, I want the uploaded form classified before extraction so that format-specific rules are applied correctly.

## Acceptance Criteria

### AC-001: Identify a supported format
- **Given**: A readable uploaded form matching a supported format marker
- **When**: Intake evaluates the document
- **Then**: The processing record stores exactly one of Format 1, Format 2, or open-source format before extraction is queued

## Edge Cases
- Conflicting format markers create an error state and do not queue extraction.
