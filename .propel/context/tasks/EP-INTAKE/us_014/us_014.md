# User Story - US_014

## Story ID
US_014

## Story Title
Show Upload Processing Status

## Status
- **State**: Draft
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
As compliance staff, I want to see the current upload processing state so that I know whether review can begin.

## Acceptance Criteria

### AC-001: Display intake outcome
- **Given**: A processing-record identifier returned from upload
- **When**: Staff opens its status
- **Then**: The interface displays the detected format and current processing state without representing an error record as approved

## Edge Cases
- A status request for an inaccessible record returns an authorization outcome without revealing document metadata.
