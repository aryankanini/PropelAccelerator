## Story Title
Handle Dependency Failures Safely
## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
As an operator, I want dependency failures isolated so that recoverable outages do not corrupt compliance workflows.
## Acceptance Criteria
### AC-001: Apply bounded recovery
- **Given**: a transient storage or LLM dependency failure
- **When**: a worker executes the operation
- **Then**: it uses bounded retries and records a recoverable failure without approving content
## Edge Cases
- An exhausted retry routes the job to the dead-letter queue.
